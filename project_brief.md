# My agent: Book Concierge (PageTurner)
One-liner: A conversational agent that helps readers discover next reads and manage reading goals with a catalog of book titles, reading history, and custom cover art.

Tool coverage:
- Memory: Favorite genres, favorite authors, pacing preferences, themes to avoid (tropes, triggers), and finished book history with ratings.
- Tools: Look up book metadata/summaries, add/remove/update reading list status (Want to Read, Currently Reading, Finished), track page progress.
- Catalog/UI: Collection of book recommendations and reading list items rendered as rich cards (cover, title, author, rating, synopsis) and reading progress tables.
- Image gen: Generates custom alternate cover art, fictional scene depictions, or thematic book badges.
- Sandbox: Calculates reading pace, estimated completion dates based on reading speed, and annual goal trajectory statistics.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for reading pace/goal completion date calculations, external book database API integration.
